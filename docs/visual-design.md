# 小爪日记 · 暮蓝放映室

2026-09-07，UI 与场景美术改版。此文档记录已应用的设计规范，玩法路线仍见 PRODUCT_TECH_PLAN.md。

## 视觉概念

把宠物房间看作一段正在发生的生活电影。以暮蓝作为安静的背景，杏橘作为温暖的注意力引导，暖纸白作为宠物档案的承载面。房间是视觉中心，辅助信息位于画面边缘。

这一版的识别元素是倾斜的拱形爪印标志、单侧大圆角的场景窗口、房间编号、细线工具栏、纸白宠物档案，以及原创猫狗矢量肖像。区别来自这些元素的组合，而非声称配色或主题绝无类似作品。

## 配色规范

| 色彩     | 色值    | 用途                         |
| -------- | ------- | ---------------------------- |
| 墨蓝     | #142936 | 主页面背景                   |
| 深海蓝   | #10222E | 深色表面与遮罩基调           |
| 蓝灰     | #38505C | 分隔线、工具栏轮廓           |
| 杏橘     | #FFA77E | 当前导航、主操作、编号与反馈 |
| 暖纸白   | #F2E9DC | 宠物档案、弹窗               |
| 月白     | #F3EEE7 | 深底主要文字                 |
| 雾蓝灰   | #A9BAC2 | 深底次要文字                 |
| 夜景冰蓝 | #BDD7E7 | 夜景选中状态与天气图标       |

深色中性区域占大部分画面；暖纸白集中在宠物档案，杏橘只用于强调。需求条允许少量不同颜色辅助区分，同时保留图标、文字和数值，不能只靠颜色传达状态。

## 字体与排版

- 品牌使用 Georgia 衬线；中文主标题使用宋体家族，正文使用本机无衬线字体。
- 移除外部 Google Fonts 下载依赖。字体外观会随系统的可用字体略有不同。
- 中文承担主要信息；英文仅用于短编号与注释，不用于唯一的功能说明。
- 桌面将 3D 场景与档案组成宽窄两列；手机先展示场景与操作，再展示档案与陪伴清单。
- 交互区域采用细线分隔，编号与图标共同建立层级。按钮有独立键盘焦点提示。

## 3D 场景

- 蓝灰墙面、较深木纹、陶土色地毯、蓝色窝垫、浅暖色沙发与杏橘色玩具球。
- 日景以暖色入射光与偏冷环境光平衡，宠物保持温暖毛色以突出轮廓。
- 夜景使用更深的蓝底、冰蓝状态色与局部暖灯，保持 UI 与场景一致。
- 场景网格、薄边框与房间编号呼应探索主题；不会遮挡画布操作。

## 组件与资产

- src/style.css：视觉变量、组件、响应式布局、减少动态效果设置。
- src/main.js：页面文案、肖像使用、场景材质色与灯光。
- public/cat-portrait.svg、public/dog-portrait.svg：本次绘制的原创矢量肖像。
- public/favicon.svg：与墨蓝、杏橘品牌色保持一致。

# 宠物运动与微动作

## 模块职责

- `PetMotor`（`src/features/pet/motion.js`）：沿已经验证的寻路折线移动，控制加减速、有限转速与到达减速。房间仍拥有根节点位置，动画不能修改导航路线。
- `FootPlanting`：在世界坐标保存支撑脚，摆动脚使用平滑轨迹向前落下。考虑模型缩放、躯干倾斜、肩部位移与地面高度后求解关节；伸展极限附近允许有限的肩髋压缩。转弯或站姿失衡时重新落脚。
- `PetComponent`：叠加肩胛运动、躯干形变、骨盆摆动、启停俯仰、转弯侧倾与头部补偿，控制视线、眼睛、耳朵和尾巴。
- `MicroBehavior`：每只宠物独立的事件时钟，可注入随机数以重放测试。暂停时不推进；更换外观不创建多个计时器。

## 输入与接入

`pet.update(mode, time, dt, motion)` 的可选 `motion` 字段：

| 字段                        | 含义                                                             |
| --------------------------- | ---------------------------------------------------------------- |
| `speed` / `acceleration`    | 世界单位每秒及每秒平方                                           |
| `turnRate` / `headingError` | 弧度每秒及目标方向差                                             |
| `groundHeight(x, z)`        | 返回脚掌位置的地面高度                                           |
| `lookTargets`               | `{ position: THREE.Vector3 }` 数组；只从房间实际提供的目标中选择 |
| `emotion`                   | `happy`、`alert`、`afraid`、`relaxed`；睡眠优先                  |
| `preview`                   | 编辑器原地步态演示，不锁定世界脚掌                               |

不提供运动输入仍兼容原有独立宠物预览。正常游戏中撒娇和玩耍触发开心尾姿，关注目标触发警觉尾姿，休闲时缓慢摆动，睡眠时几乎静止。`afraid` 留作未来惊吓事件输入；当前小屋不会随机惊吓宠物。

眨眼在 2.2–8.5 秒之间重新抽样，支持单眨、双眨和眯眼。耳朵事件按 70% 保持、10% 左耳、10% 右耳、5% 前倾、5% 抖耳抽样。视线有独立的停留和释放时间，不会永远盯住鼠标。声音目标只在环境音开启时加入，并使用摄像机位置代表听觉注意方向。

## 验证与边界

单元测试覆盖 30 / 60 / 120 帧的移动到达与拐点路径，猫狗及 80% / 100% 体型的支撑脚接触，启停俯仰和头部反向补偿，以及随机事件变体与睡眠抑制。平地测试中支撑脚踝与锁定点误差要求小于体型乘以 0.003 世界单位。

当前仍是程序化半写实模型，肩胛与骨盆是近似的肌肉和关节运动，不是经过动作捕捉校准的解剖骨骼；腿部仍为两节求解。复杂地形、快速奔跑及任意家具碰撞不属于完整物理仿真的保证范围。编辑器的起停演示主动重复，真实待机事件不按固定周期重复。
